# Worked label examples

Weak vs strong wording. Read only when you need inspiration for a tricky item.

| Weak | Strong | Why |
| --- | --- | --- |
| `SENSOR MODULE` | `HC-SR04` / `ULTRASONIC DISTANCE SENSOR` / `ROBOT OBSTACLE DETECTION` | Model + function + use |
| `CHARGER BOARD` | `TP4056 USB-C` / `1S LI-ION CHARGER` / `BATTERY PROJECTS` | Specific family and job |
| `STUFF FOR CAR` | `ROBOT CAR KIT` / `READY TO BUILD` | Box: short heading, one status detail |
| `HARD DRIVE PARTS - MAGNETS` | `HARD DRIVE PARTS` / `MAGNETS / MOTOR SCREWS` / `ARMS` | No em-dash or hyphen-as-dash; slashes |
| `USB 1` | `UBUNTU SRV 24.04.3` | Names the verified contents |
| `32GB USB DRIVE EMPTY BLANK` | `EMPTY 32GB` | Shortest unambiguous name |
